# لوحة تحكم متابعة التحويلات المالية | شريف & عبدالله 💰🤝

تطبيق ويب مصمم خصيصاً لمتابعة التحويلات المالية الشهرية (500 جنيه شهرياً) بين **شريف** و **عبدالله** مع حفظ صور الإيصالات ومشاركتها والاطلاع عليها في أي وقت.

---

## 🌟 مميزات اللوحة:
1. **التبديل السريع بين المستخدمين**: زر لاختيار من يقوم بالاستخدام حالياً (**شريف** أو **عبدالله**).
2. **رفع ومعاينة الإيصالات**: إمكانية رفع صورة التحويل (من الموبايل أو الكمبيوتر) ومعاينتها وتكبيرها وتنزيلها بدقة كاملة.
3. **تتبع المبلغ الإجمالي وتوزيع الدفعات**:
   - إجمالي ما تم تحصيله حتى الآن بالجنيه المصري.
   - ما دفعه **شريف** وعدد شهوره.
   - ما دفعه **عبدالله** وعدد شهوره.
   - مؤشر التوازن (يوضح هل الطرفان متعادلان أم أحدهما متقدم بمبلغ معين).
4. **جدول التزام الشهور**: جدول يوضح كل شهر من دفع فيه ومن لم يدفع بعد.
5. **سجل التحويلات**: فلترة التحويلات بحسب الشخص مع التاريخ والوقت ووسيلة التحويل (انستاباي، فودافون كاش، إلخ) وملاحظات التحويل.
6. **تحديث تلقائي حي**: عند قيام أي طرف برفع إيصال، تظهر البيانات عند الطرف الآخر تلقائياً.

---

## 🚀 كيفية التشغيل:

### الطريقة الأولى: التشغيل الكامل (مع حفظ الصور ومشاركتها)

1. افتح موجه الأوامر (Terminal / PowerShell) في مجلد المشروع:
   ```bash
   cd "C:\Users\HP\.gemini\antigravity\scratch\sherif-abdullah-dashboard"
   ```

2. قم بتثبيت الحزم المطلوبة (مرة واحدة فقط):
   ```bash
   npm install
   ```

3. شغّل السيرفر:
   ```bash
   npm start
   ```

4. افتح المتصفح على الرابط:
   👉 **http://localhost:3000**

---

## 🌐 كيف تفتح اللوحة على الهاتف وتشاركها مع الطرف الآخر؟

### 1. المشاركة على نفس شبكة الواي فاي المنزلية (Wi-Fi):
- اعرف عنوان IP الخاص بجهازك (مثلاً: `192.168.1.5`).
- يمكنك أنت وعبدالله فتح المتصفح على التليفون وكتابة:
  `http://192.168.1.5:3000`

### 2. المشاركة عبر الإنترنت من أي مكان (أسهل طريقة مجانية ومباشرة):
أثناء تشغيل السيرفر، افتح نافذة جديدة في موجه الأوامر واكتب:
```bash
npx localtunnel --port 3000
```
أو باستخدام Cloudflare Tunnel مجاناً:
```bash
npx cloudflared tunnel --url http://localhost:3000
```
سيعطيك رابطاً عاماً مثل `https://sherif-abdullah.loca.lt` يمكنك إرساله لعبدالله في واتساب ليفتح اللوحة من هاتفه ويرفع صور التحويلات وتظهر عندك فوراً.

### 3. الاستضافة السحابية الدائمة المجانية (24 ساعة بدون الحاجة لكمبيوترك):
يمكنك رفع هذا المشروع مجاناً 100% على منصة مثل **[Render.com](https://render.com)** أو **[Railway](https://railway.app)**:
- فقط قم برفع المجلد على GitHub وربطه بـ Render كـ Web Service.
- ستحصل على رابط دائم يعمل 24 ساعة يومياً مجاناً لك ولعبدالله.

## 💻 التجربة السريعة للواجهة (بدون سيرفر):
يمكنك فتح ملف `public/index.html` مباشرة بالنقر المزدوج عليه في أي متصفح (Edge أو Chrome)، وسيعمل التطبيق في **وضع التجربة المحلية** لحفظ البيانات على المتصفح مباشرة.
